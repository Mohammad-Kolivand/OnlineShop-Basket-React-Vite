# Online Shop with Basket 🛒

A responsive e-commerce interface built with React and Vite. Browse products, view product details, and manage your shopping basket.

## 🚀 Live Demo

**[View the live shop on Vercel](https://online-shop-basket-react-vite.vercel.app/)**

## Features

- Browse the product catalog
- Search and filter products
- View product details
- Add, increase, decrease, and remove items from the basket
- Calculate basket totals
- Responsive layout for different screen sizes

## Tech Stack

- React
- Vite
- CSS Modules and CSS

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/Mohammad-Kolivand/OnlineShop-Basket-React-Vite.git
cd OnlineShop-Basket-React-Vite
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
